# Security policy

## Supported versions

The project is experimental. Only the latest public release or the current default branch is considered for security fixes.

## Reporting a vulnerability

Do not report vulnerabilities through a public issue and do not attach private project files or game assets.

After the repository is made public, use GitHub's **Security** tab and select **Report a vulnerability** to open a private security advisory. Include the affected version, impact, reproduction steps, and a minimal proof of concept that contains no third-party game content.

If private vulnerability reporting is not available yet, wait for a private reporting channel to be published rather than disclosing the issue publicly.
