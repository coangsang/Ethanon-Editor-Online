# Contributing

The project is currently experimental. Bug reports are welcome, but feature requests and pull requests are not being accepted yet.

## Reporting a bug

Before opening an issue:

1. Reproduce the problem with the latest available version.
2. Back up the affected project.
3. Check that the problem is not already reported.

Include the editor version or commit, platform, reproduction steps, expected and actual behavior, and sanitized logs. Use a minimal synthetic fixture when a file is required.

Do not upload copyrighted game assets, extracted scenes, private projects, credentials, or personal information. Reports that require such content cannot be investigated through the public issue tracker.

## Security issues

Do not open a public issue for a vulnerability. Follow [SECURITY.md](SECURITY.md).
